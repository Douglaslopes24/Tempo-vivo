# Suporte

Use [Issues](https://github.com/Douglaslopes24/Tempo-vivo/issues) para erros e sugestões. Informe a versão do Ceuvia, do Home Assistant, o navegador e os passos para reproduzir.

Para erro de cartão ausente, confira primeiro o [guia de instalação](README.md#se-o-cartão-não-aparecer). Para atualizar uma instalação anterior, use o [guia de migração](docs/MIGRATION.md).

O card apresenta os estados das suas entidades. Escolha os sensores no editor visual; valores de demonstração e nomes de entidades de exemplo precisam ser substituídos pelos seus dados.
