# Identidade do projeto

- Marca: **Ceuvia**
- Produto: **Ceuvia Weather Card**
- Descrição: **Animated Weather Card for Home Assistant**
- Slogan: **O clima ganha vida.**
- Nome sugerido para a URL: `ceuvia-weather-card`
- Endereço atual: `Douglaslopes24/Tempo-vivo`

A marca é aplicada nos arquivos, no HACS, na integração e no seletor de cartões. A renomeação da URL requer a opção **Settings → General → Repository name** do GitHub. Se o proprietário alterar a URL para `ceuvia-weather-card`, o GitHub redireciona os links antigos; as referências da documentação podem ser atualizadas depois.

Descrição sugerida para o campo About:

> Animated Weather Card for Home Assistant with natural transitions, indoor sensors and a visual editor.

Tópicos sugeridos:

`home-assistant`, `hacs`, `lovelace`, `weather-card`, `animated-weather`, `ceuvia`

O domínio interno `tempo_vivo` preserva os sensores de instalações anteriores. Não é necessário renomeá-lo para usar a marca Ceuvia.
